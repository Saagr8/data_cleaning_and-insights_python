# data_cleaning_and-insights_python
A basic Python project where I practiced cleaning data, handling simple data problems, finding basic insights, and creating a simple recommendation feature.
This is a basic Python project I made while learning Python and data handling as part of my AI/ML learning.

The main idea of this project was to think about data from the beginning:
1. Load the data
2. Find problems in the data
3. Clean and structure the data
4. Get some basic insights
5. Create a simple recommendation feature

## What I practiced
- Loading JSON data
- Functions
- Lists
- Dictionaries
- Sets
- Loops
- If statements
- Handling missing values
- Removing duplicate data
- Cleaning text data
- Converting values into numbers
- Basic calculations

## What I did with the data
The data had some simple problems, such as:
- Ratings could be written as words instead of numbers
- Some values could have extra spaces
- Some users could have missing information
- There could be duplicate users

I used Python to clean some of these problems before working with the data.

## Basic insights
After cleaning the data, I tried to find some simple information from it, such as:
- Average user rating
- Percentage of users with a poor rating

## Simple recommendation
I also added a simple recommendation feature based on the user's rating.
For example:
- Rating 4 or above → Apple
- Rating below 4 → Samsung

This is just a simple rule I created for practice. It is not a machine learning recommendation system.
## What I learned

This project helped me understand that when working with data, I first need to understand the data and find problems in it before trying to get useful information from it.
I also started understanding how Python can be used to clean data and get meaningful information from it.
